## I. MỤC TIÊU CỦA BƯỚC NÀY
Xây dựng API đăng nhập (`POST /auth/login`), sinh cặp token (Access Token & Refresh Token) và trả về an toàn cho trình duyệt thông qua **HttpOnly Cookie**.

---

## II. HÌNH DUNG ĐƠN GIẢN VỀ CẶP TOKEN

* **Access Token (Thẻ tạm 15 phút):** Giống như chiếc vé đeo cổ dùng trong ngày. Nó chứa thông tin của bạn (`userId`, `role`) để đi qua cổng bảo vệ các API. Nó tự hết hạn sau 15 phút và không cần lưu vào cơ sở dữ liệu.
* **Refresh Token (Chứng minh thư 7 ngày):** Chứa mã vạch `jti`. Nó được cất an toàn trong chiếc két sắt của trình duyệt (**HttpOnly Cookie**), JavaScript không thể chạm vào. Mỗi khi thẻ tạm 15 phút hết hạn, trình duyệt sẽ mang tấm chứng minh thư này lên để đổi thẻ tạm mới.

```typescript
async login(email: string, pass: string, deviceId = 'default_browser') {
  if (email !== 'admin@example.com' || pass !== 'Password123@') {
    throw new UnauthorizedException('Email hoặc mật khẩu không chính xác');
  }

  const user = { userId: 'usr_998877', email, role: 'ADMIN' };
  return await this.generateTokenPair(user, deviceId);
}
```

### Bước 2: Sinh `jti` và ký 2 loại token
```typescript
private async generateTokenPair(user: UserPayload, deviceId: string) {
  // 1. Sinh mã jti ngẫu nhiên duy nhất (UUID v4)
  const jti = randomUUID();

  // 2. Ký Access Token ngắn hạn (15 phút)
  const accessToken = this.jwtService.sign(
    { sub: user.userId, email: user.email, role: user.role },
    { secret: process.env.JWT_ACCESS_SECRET, expiresIn: '15m' }
  );

  // 3. Ký Refresh Token dài hạn (7 ngày), nhúng kèm jti và deviceId
  const refreshToken = this.jwtService.sign(
    { sub: user.userId, deviceId, jti },
    { secret: process.env.JWT_REFRESH_SECRET, expiresIn: '7d' }
  );

  // 4. Lưu jti vào Redis Whitelist với thời gian sống 7 ngày
  await this.redisService.setSession(user.userId, deviceId, jti, 7 * 24 * 3600);

  return { user, accessToken, refreshToken, refreshTokenTtlSeconds: 7 * 24 * 3600 };
}
```

### Bước 3: Đặt Cookie trên Controller và trả Access Token
Mở file: [`src/auth/auth.controller.ts`](file:///home/hy/Documents/Obsidian%20Vault/Tranning/B%C3%A0i%2001%20-%20Authentication%20&%20Session%20Management/02.%20Th%E1%BB%B1c%20h%C3%A0nh/backend-nestjs/src/auth/auth.controller.ts)

```typescript
@Post('login')
async login(@Body() dto: LoginDto, @Res({ passthrough: true }) res: Response) {
  const result = await this.authService.login(dto.email, dto.pass, dto.deviceId);

  // Ghi chỉ thị Set-Cookie gửi về Trình duyệt
  res.cookie('refreshToken', result.refreshToken, {
    httpOnly: true,  // JavaScript hoàn toàn KHÔNG THỂ đọc được (chống XSS 100%)
    secure: false,   // Đặt true khi chạy Production (chỉ gửi qua HTTPS)
    sameSite: 'lax', // Trình duyệt không gửi lén khi bị web khác dụ bấm (chống CSRF)
    path: '/',
    maxAge: result.refreshTokenTtlSeconds * 1000,
  });

  // Access Token trả về trong Body JSON để Frontend lưu tạm trong RAM
  return {
    message: 'Đăng nhập thành công',
    user: result.user,
    accessToken: result.accessToken,
  };
}
```

Mở file: [`src/app/login/page.tsx`](file:///home/hy/Documents/Obsidian%20Vault/Tranning/B%C3%A0i%2001%20-%20Authentication%20&%20Session%20Management/02.%20Th%E1%BB%B1c%20h%C3%A0nh/frontend-nextjs/src/app/login/page.tsx)

1. Form gửi yêu cầu đăng nhập sang Backend:
   ```typescript
   const data = await apiClient('/auth/login', {
     method: 'POST',
     body: JSON.stringify({ email, pass: password, deviceId: 'Chrome_Mac' }),
   });
   ```
2. **Cơ chế tự động của Trình duyệt:** Trình duyệt nhìn thấy header `Set-Cookie` từ backend trả về và **tự động lưu `refreshToken` vào Cookie Jar**.
3. **Frontend lưu trữ Access Token:** Lưu biến `data.accessToken` vào bộ nhớ RAM của ứng dụng (`setAccessToken(data.accessToken)`), không lưu vào `localStorage`.
