## I. MỤC TIÊU CỦA BƯỚC NÀY
Xây dựng cơ chế **xoay vòng token (Token Rotation)** khi Access Token 15 phút hết hạn và kích hoạt lá chắn **phát hiện kẻ tấn công dùng lại token cũ (Replay Attack Detection)**.

---

## II. HÌNH DUNG ĐƠN GIẢN VỀ CƠ CHẾ XOAY VÒNG VÀ BẮT HACKER

* **Tình huống bình thường (Người dùng hợp lệ):**
  * Sau 15 phút, Access Token hết hạn.
  * Trình duyệt tự mang Refresh Token (đang giữ vé có mã `jti_1`) lên gặp Server để đổi vé mới.
  * Server mở sổ Redis ra kiểm tra: *"Đúng rồi, tài khoản này đang giữ vé `jti_1`"*.
  * Server xé vé cũ `jti_1` đi, cấp vé mới `jti_2`, ghi đè `jti_2` vào sổ Redis và trả vé mới về cho bạn.
* **Tình huống bị tấn công (Hacker nhặt được vé cũ `jti_1`):**
  * Bạn đã đổi sang `jti_2` rồi.
  * 5 phút sau, hacker mang vé cũ `jti_1` lên đòi đổi vé mới.
  * Server mở sổ Redis ra: *"Ủa? Trong sổ của tôi vé hiện tại là `jti_2`. Cái vé `jti_1` này ĐÃ BỊ DÙNG TỪ TRƯỚC RỒI! Có kẻ vừa đánh cắp vé!"*.
  * **Hành động khẩn cấp:** Server xé sổ xóa sạch mọi phiên của tài khoản này trong Redis $\rightarrow$ Chặn đứng hacker và bảo vệ an toàn cho chủ tài khoản.

## III. BƯỚC LÀM CỤ THỂ TRONG BACKEND (NESTJS)

Mở file: [`src/auth/auth.service.ts`](file:///home/hy/Documents/Obsidian%20Vault/Tranning/B%C3%A0i%2001%20-%20Authentication%20&%20Session%20Management/02.%20Th%E1%BB%B1c%20h%C3%A0nh/backend-nestjs/src/auth/auth.service.ts)

Hàm `refresh()` thực hiện đúng 4 bước kiểm tra chặt chẽ:

```typescript
async refresh(refreshTokenString: string) {
  if (!refreshTokenString) {
    throw new UnauthorizedException('Không tìm thấy Refresh Token trong Cookie');
  }

  // 1. Giải mã và kiểm tra chữ ký của Refresh Token
  const payload = this.jwtService.verify<RefreshTokenPayload>(refreshTokenString, {
    secret: process.env.JWT_REFRESH_SECRET,
  });

  const { userId, deviceId, jti } = payload;

  // 2. Tra cứu mã jti đang lưu trong Redis Whitelist
  const storedJti = await this.redisService.getSession(userId, deviceId);

  if (!storedJti) {
    throw new UnauthorizedException('Phiên đăng nhập không tồn tại hoặc đã hết hạn');
  }

  // 3. 🚨 BẮT LỖI REPLAY ATTACK: Mã jti gửi lên KHÁC với jti đang lưu trong Redis
  if (storedJti !== jti) {
    console.error(`🚨 [BÁO ĐỘNG] Phát hiện dùng lại Refresh Token cũ cho User: ${userId}!`);
    
    // Tự động hủy toàn bộ phiên của người dùng trên mọi thiết bị
    await this.redisService.deleteAllSessions(userId);

    throw new UnauthorizedException(
      'Phát hiện hành vi bất thường (Token reuse). Toàn bộ phiên đã bị đăng xuất để bảo vệ bạn!',
    );
  }

  // 4. NẾU KHỚP HỢP LỆ: Xoay vòng Token (Cấp jti mới, ghi đè Redis)
  const user = { userId: payload.userId, email: payload.email, role: payload.role };
  return await this.generateTokenPair(user, deviceId);
}
```

Ở file [`src/auth/auth.controller.ts`](file:///home/hy/Documents/Obsidian%20Vault/Tranning/B%C3%A0i%2001%20-%20Authentication%20&%20Session%20Management/02.%20Th%E1%BB%B1c%20h%C3%A0nh/backend-nestjs/src/auth/auth.controller.ts):
```typescript
@Post('refresh')
async refresh(@Req() req: Request, @Res({ passthrough: true }) res: Response) {
  // Trình duyệt tự động gửi cookie 'refreshToken' lên qua req.cookies
  const refreshToken = req.cookies?.['refreshToken'];
  const result = await this.authService.refresh(refreshToken);

  // Ghi đè Refresh Token mới vào Cookie của trình duyệt
  res.cookie('refreshToken', result.refreshToken, {
    httpOnly: true,
    sameSite: 'lax',
    path: '/',
    maxAge: result.refreshTokenTtlSeconds * 1000,
  });

  return { message: 'Làm mới phiên thành công', accessToken: result.accessToken };
}
```

Để người dùng không bị văng ra màn hình đăng nhập mỗi 15 phút, hàm `apiClient` tự động làm mới ngầm dưới nền:

```typescript
// Khi API trả về mã lỗi 401 Unauthorized:
if (response.status === 401) {
  // 1. Tạm dừng các request khác và đưa vào hàng đợi chờ
  // 2. Gửi request POST /auth/refresh (trình duyệt tự đính kèm HttpOnly Cookie)
  const refreshRes = await fetch('http://localhost:4000/auth/refresh', {
    method: 'POST',
    credentials: 'include', // 👉 Bắt buộc để gửi nhận Cookie
  });

  const { accessToken } = await refreshRes.json();
  setAccessToken(accessToken); // Cập nhật Access Token mới vào RAM

  // 3. Tự động gửi lại request ban đầu với Access Token mới
  headers.set('Authorization', `Bearer ${accessToken}`);
  return await fetch(url, fetchConfig);
}
```
