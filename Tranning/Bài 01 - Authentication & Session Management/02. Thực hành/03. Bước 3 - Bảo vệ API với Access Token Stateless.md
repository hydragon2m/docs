## I. MỤC TIÊU CỦA BƯỚC NÀY
Hiểu cách Backend bảo vệ các Endpoint nhạy cảm (như xem trang cá nhân, giỏ hàng, thông tin thanh toán) bằng **Access Token** với tốc độ cực nhanh mà **không cần chạm vào Database hay Redis**.

---

## II. HÌNH DUNG ĐƠN GIẢN VỀ CƠ CHẾ STATELESS GUARD

* Hãy tưởng tượng bảo vệ soát vé tại cổng rạp chiếu phim:
  * Người soát vé **chỉ cần nhìn con dấu mộc chữ ký đỏ chót** trên tấm vé Access Token.
  * Nếu con dấu đúng (`SECRET_KEY` hợp lệ) và giờ xem phim chưa qua (`exp` chưa hết hạn) $\rightarrow$ Cho bạn vào rạp ngay lập tức!
  * Người soát vé **không cần phải gọi điện thoại vào kho dữ liệu** để hỏi lại xem vé này có thật không. Nhờ đó, hàng ngàn người đi qua cổng soát vé mỗi giây mà không bị ùn tắc.

## III. 3 BƯỚC TRIỂN KHAI TẠI BACKEND (NESTJS)

### Bước 1: Tạo Passport JWT Strategy
Mở file: [`src/auth/strategies/jwt.strategy.ts`](file:///home/hy/Documents/Obsidian%20Vault/Tranning/B%C3%A0i%2001%20-%20Authentication%20&%20Session%20Management/02.%20Th%E1%BB%B1c%20h%C3%A0nh/backend-nestjs/src/auth/strategies/jwt.strategy.ts)

Chiến lược này hướng dẫn NestJS cách trích xuất token từ header `Authorization: Bearer <token>`:
```typescript
@Injectable()
export class JwtStrategy extends PassportStrategy(Strategy) {
  constructor() {
    super({
      jwtFromRequest: ExtractJwt.fromAuthHeaderAsBearerToken(), // 1. Lấy Bearer token
      ignoreExpiration: false,                                  // 2. Tự động từ chối nếu hết hạn
      secretOrKey: process.env.JWT_ACCESS_SECRET,               // 3. Dùng Secret Key verify chữ ký
    });
  }

  // Nếu chữ ký hợp lệ, dữ liệu payload giải mã được sẽ nạp vào req.user
  async validate(payload: any) {
    return {
      userId: payload.sub,
      email: payload.email,
      role: payload.role,
    };
  }
}
```

### Bước 2: Tạo Auth Guard bảo vệ Endpoint
Mở file: [`src/auth/guards/jwt-auth.guard.ts`](file:///home/hy/Documents/Obsidian%20Vault/Tranning/B%C3%A0i%2001%20-%20Authentication%20&%20Session%20Management/02.%20Th%E1%BB%B1c%20h%C3%A0nh/backend-nestjs/src/auth/guards/jwt-auth.guard.ts)

```typescript
@Injectable()
export class JwtAuthGuard extends AuthGuard('jwt') {
  handleRequest(err: any, user: any) {
    if (err || !user) {
      throw err || new UnauthorizedException('Access Token không hợp lệ hoặc đã hết hạn');
    }
    return user;
  }
}
```

### Bước 3: Áp dụng Guard lên Controller
Mở file: [`src/auth/auth.controller.ts`](file:///home/hy/Documents/Obsidian%20Vault/Tranning/B%C3%A0i%2001%20-%20Authentication%20&%20Session%20Management/02.%20Th%E1%BB%B1c%20h%C3%A0nh/backend-nestjs/src/auth/auth.controller.ts)

Chỉ cần gắn decorator `@UseGuards(JwtAuthGuard)` lên bất kỳ hàm nào:
```typescript
@Get('profile')
@UseGuards(JwtAuthGuard)
getProfile(@Req() req: any) {
  // Biến req.user được sinh ra tự động từ Payload của Access Token
  return {
    message: 'Xác thực thành công không cần chạm Database/Redis!',
    user: req.user,
  };
}
```
