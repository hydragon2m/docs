## I. MỤC TIÊU CỦA BƯỚC NÀY
Hiểu và triển khai các tình huống thu hồi phiên đăng nhập:
1. Đăng xuất trên thiết bị hiện tại (Single Logout).
2. Đăng xuất khỏi toàn bộ thiết bị (Kick-out All Sessions khi đổi mật khẩu).
3. Thu hồi tức thì Access Token còn hạn (Short-lived Blacklist).

## III. BƯỚC LÀM CỤ THỂ TRONG CODE BACKEND (NESTJS)

Mở file: [`src/auth/auth.controller.ts`](file:///home/hy/Documents/Obsidian%20Vault/Tranning/B%C3%A0i%2001%20-%20Authentication%20&%20Session%20Management/02.%20Th%E1%BB%B1c%20h%C3%A0nh/backend-nestjs/src/auth/auth.controller.ts)

### 1. Đăng xuất trên thiết bị hiện tại (`POST /auth/logout`)
Người dùng bấm "Đăng xuất" trên máy tính cá nhân. Thiết bị điện thoại vẫn được giữ nguyên đăng nhập:

```typescript
@Post('logout')
@UseGuards(JwtAuthGuard)
async logout(@Req() req: any, @Res({ passthrough: true }) res: Response) {
  const userId = req.user.userId;
  const deviceId = req.headers['user-agent'] || 'unknown_browser';

  // 1. Xóa key phiên của thiết bị này trên Redis
  await this.authService.logout(userId, deviceId);

  // 2. Chỉ thị trình duyệt xóa sạch Cookie refreshToken
  res.clearCookie('refreshToken', {
    httpOnly: true,
    sameSite: 'lax',
    path: '/',
  });

  return { message: 'Đã đăng xuất thiết bị hiện tại thành công' };
}
```

### 2. Đăng xuất khỏi mọi thiết bị (`POST /auth/logout-all`)
Người dùng vừa **đổi mật khẩu** hoặc bấm *"Đăng xuất khỏi tất cả các thiết bị khác"*:

```typescript
@Post('logout-all')
@UseGuards(JwtAuthGuard)
async logoutAll(@Req() req: any, @Res({ passthrough: true }) res: Response) {
  const userId = req.user.userId;

  // Xóa toàn bộ key dạng "session:<userId>:*" trên Redis
  await this.authService.logoutAll(userId);

  // Xóa Cookie ở máy hiện tại
  res.clearCookie('refreshToken', { httpOnly: true, sameSite: 'lax', path: '/' });

  return { message: 'Đã đăng xuất thành công khỏi toàn bộ các thiết bị' };
}
```

### 3. Kỹ thuật nâng cao: Thu hồi khẩn cấp Access Token còn hạn (Blacklist ngắn hạn)
Nếu hệ thống ngân hàng hoặc tài chính yêu cầu: *Khi bấm Logout, Access Token phải chết ngay lập tức, không được phép chờ 15 phút*:

```typescript
// Khi Logout, lưu jti của Access Token vào Redis Blacklist
const remainingTtlSeconds = payload.exp - Math.floor(Date.now() / 1000);
if (remainingTtlSeconds > 0) {
  await redisClient.set(`blacklist:access:${payload.jti}`, '1', 'EX', remainingTtlSeconds);
}
```
Trong `JwtAuthGuard`, sau khi kiểm tra chữ ký, kiểm tra nhanh thêm 1 dòng:
```typescript
const isBlacklisted = await redisClient.exists(`blacklist:access:${payload.jti}`);
if (isBlacklisted) throw new UnauthorizedException('Token đã bị vô hiệu hóa');
```
* **Điểm thông minh:** Key blacklist này **chỉ sống đúng bằng số phút còn lại của token** rồi tự động biến mất khỏi RAM. Không bao giờ lo phình to bộ nhớ!
